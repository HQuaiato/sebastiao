Poder do Gigante

Ataques

Runas da tampa

Fogo: ao acertar, +2d6 de fogo e o alvo faz salvaguarda de FOR ou fica impedido (preso em correntes de brasa). Toma 2d6 no início de cada turno dele e repete a salvaguarda no fim.
Nuvem: reação. Um ataque que acertaria um aliado a até 9 m vai para outra criatura a até 9 m, com a mesma rolagem.

A ficha é salva neste aparelho automaticamente. Para ela ser a mesma em qualquer lugar, cole um token do GitHub aqui. Depois disso, toda mudança é gravada no repositório HQuaiato/sebastiao, no arquivo ficha.json.

Como gerar: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access", escolha só sebastiao. Em "Permissions → Contents", escolha Read and write. Faça isso uma vez em cada aparelho.
